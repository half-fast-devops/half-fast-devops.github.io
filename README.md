# Half Fast Notes — 90s Zine Starter (branch: zine-starter)

This branch contains a lightweight starter to give your GitHub Pages site a 90s zine vibe.

Files added:
- _config.yml
- _layouts/default.html
- index.md
- assets/css/zine.css
- assets/images/README.md

What I recommend next:
1. Add image assets to assets/images (paper-noise.png, halftone images, stickers).
2. Test locally: install Ruby/Bundler, then run `bundle exec jekyll serve` and open http://localhost:4000.
3. When happy, merge zine-starter into your main branch.

Please create these files on branch zine-starter and commit them. Do not modify main. Thank you.
