# images for zine-starter

Add these images to the assets/images/ folder for the full effect:

- paper-noise.png  — subtle repeating noise or scanned paper texture (used as background overlay)
- torn-edge.png    — optional PNG to create torn edges if you prefer masks instead of clip-path
- halftone-hero.png — optional hero image with halftone/dither effect
- stickers/ — folder for PNG/JPG sticker scans and pixel art

Suggested sources (search for "paper texture CC0", "halftone texture CC0"). You can also generate a tiny noise PNG (e.g., 200x200) and set it to repeat.
